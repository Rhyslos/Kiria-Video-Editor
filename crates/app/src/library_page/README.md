# library_page

The Library page (build plan 5.2): every file of the project by type and in the person's own lists, filtered by labels and smart filters, with a detail panel to look at one file, mark the part wanted and add it to the timeline. `../library_page.rs` holds the page's state (`LibraryPage`), what it asks the library index (`query`), what it hands the window (`Picked`) and the layout; the window side is `../editor/library_ui.rs`.

| File | What it holds |
|---|---|
| `arrange.rs` | Worked out without drawing: `Facts` (clips and timelines using each file, over the project; files of the open tab per label and per smart filter; files per type for the tabs) and `arrange` (the index's answer grouped by label, folder or nothing, in lines of cards or rows with each line's top, so `Arranged::in_view` gives only the lines on screen). The page works both out again only when the project, the answer or a choice changed, or a second has passed (proxy states change on their own) |
| `top_rows.rs` | The tab bar (`ui_kit::tab_strip`: Video, Audio, Images, Effects, then the custom lists and "+ New list"; scrolls and fades when full; right-click a list to rename or remove it; a list just made opens) and the filter row ("Find" words, the label and smart filter chips to take off, group by, sort, thumbnail size, grid / rows) |
| `sidebar.rs` | Import (with how many files are being checked), the labels with their counts in the open tab (click: a chip; right-click: rename, colour, every project, remove; "+" makes an empty label), labels offered in every project that the project hasn't got (dimmed, "everywhere"; right-click to add or stop offering), the smart filters (Not in a timeline, Needs proxy, End missing, Can't be found, With a note) and Prune (opens the Prune dialog, `Action::Prune`) |
| `cards.rs` | Pictures (and anything in a list) as a thumbnail grid or rows: the file's picture from the clip pictures already read for the timeline (`ClipPictures`, a third of the way in; the pointer across it skims), a sound file's waveform instead, a coloured edge for its labels, "In timeline", "Needs proxy" (or the build's progress) and "End missing" badges, the length, name and details. Click selects, double-click adds, right-click: add, insert, proxy, Labels / Lists / Note (`crate::organise`) |
| `sound_rows.rs` | The Audio tab's rows: play button (the panel's player), name and format ("WAV · 48 kHz · stereo"), the waveform across the row in the first label's colour (`ui_kit::waveform`), "In timeline", length; the file in the panel shows the player's place and its marked part on its waveform, which scrubs it |
| `detail.rs` | The detail panel (`layout::RIGHT_PANEL_WIDTH`, as the Edit inspector): the preview (video: the player's picture with the shared transport over it and `ui_kit::scrub` under it; an image; sound: a large waveform with the transport), mark in / out (the shortcut table's `MarkIn` / `MarkOut`) and what is marked, "Add to timeline" and "Insert at the edit point", then the Sound (loudness, true peak, the problem and its one-click level), File, Labels, Lists and Note sections (`ui_kit::inspector::section`) |
| `player.rs` | `Player`: one file on its own. The picture is a third viewer (`Viewer::second`, slot 2) asked for the file alone (`engine::source::file_alone`); the sound is `engine::Playback` of a timeline holding only that file (`listening_project`, made with the import command), whose clock moves the picture. Pausing goes back to where playing began, Stop stays, playing stops at the out mark |
| `loudness.rs` | `Measurements`: each sound stream of a file (game, microphone, chat…) decoded once on a worker and measured with `engine::loudness` (integrated loudness, highest true peak), kept for the session. `advice`: the problem in a sentence (peaks over -1 dBTP, or more than 1 LU from the loudness aimed for in Settings) and the level change that fixes it without pushing the peaks over -1 dBTP; the detail panel shows each stream under the name the import gave it, with its own fix |
| `uses.rs` | `Use` (a file's marks and the level of each sound stream) and `Uses`, the page's working copy. Where they are kept is a setting (Settings › Library): for the session (nothing written to the project), or in the project (`project::MediaUse`, format 15), each change going out as one `SetMediaUses` command and the page following the project every frame, so undo shows at once. Switching to the project writes the session's marks into it at once, as one step (`write_all`) |
| `placing.rs` | "Add to timeline": the whole file as it is is `PlaceMedia` or `InsertMedia`; a marked part or a changed level is a template made on the spot (the file placed at the end of a copy of the timeline, the marked stretch captured, each sound stream's level put on that stream's clips) dropped in with `InsertTemplate`, so it lands on the tracks the whole file would and undoes in one step. `says`, the status line |

## Rules

- Never ask the index on the interface thread: the page reads `library::Live`'s newest answer and works with what it has (an answer for another tab is not shown; until the right one comes the tab's files are listed by name).
- Draw only what is on screen: lines come from `Arranged::in_view`, thumbnails and waveforms are asked for only for files in view.
- Marks and chosen levels are kept for the session unless Settings › Library says to save them in the project; then every change is a command, never a write behind the history's back.
