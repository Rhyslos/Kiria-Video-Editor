# export_page

The parts of the Export page (`../export_page.rs` lays the page out: presets left, settings middle with the checks under them, the summary right, the queue along the bottom).

| File | What it holds |
|---|---|
| `choice.rs` | `Choice`: what the settings say apart from the file and the range (container, picture and sound codecs, quality, `FrameSize`, frame rate, normalise, processor only, the WAV beside), turned into the engine's `ExportSettings` with `settings`; `settle` keeps the codecs to ones the container holds and this machine encodes. `FrameSize`: the timeline's, so many lines on the shorter side with the timeline's shape kept (1080 is 1920×1080 for a wide timeline, 1080×1920 for a tall one), or exact (the picture fitted inside with black bars). `LOWER_RATES`: the frame rates offered below the timeline's. `plays_on`: what a format plays on, in plain words (what reads it, never which programs) |
| `presets.rs` | The built-in presets (Web 1080p, Web 4K, Vertical 1080×1920, Archive master, Small preview, Audio only WAV and MP3; those preferring H.265 take H.264 where it can't be encoded) and the person's own: `OwnPresets`, one small file `export-presets.ron` in the app's data folder with its own format version, codecs written by short names of their own; a newer or damaged file is refused and left alone |
| `checks.rs` | The checks in plain words, each with a one-click fix where there is one (`list`, pure): media the timeline plays (through nested timelines) that can't be found, whether this machine encodes the format, loudness and peaks, effects to render first (none need it: every effect is drawn as the file is written), black bars and a picture made larger than the timeline, the file name, a file that will be replaced, the folder and the free space. `LoudnessWatch` measures the mix on a worker (`engine::export::measure_mix`) again 0.7 s after the timeline or the stretch changed; `DiskWatch` looks at the folder, its drive's free space and the file on a worker, every 5 s |
| `queue.rs` | `Queue`: exports one at a time in the background, each the timeline as it was when added. Export puts a job in line (it starts when nothing else runs), Add to queue holds it until Start; Pause (the worker waits between frames), Resume, Cancel, Try again, Edit (back onto the page), Remove. Owned by the window, polled every frame on every page |
| `words.rs` | How things are said: sizes, times, a job's progress and how it went, the sound measured. `Pace`: how fast exports went on this machine (kept in settings, learned from each export of a second or more: pictures in millions of pixels a second, on the graphics card and on the processor apart, sound alone in seconds a second), and `estimate`, which says when it is still a guess |
