# Changelog

## 0.1.0

The first installable build. Nothing to edit yet: this release sets up the foundations everything else is built on.

- Windows installer and Linux AppImage, with automatic, signed updates.
- The editor window with the five pages (Library, Edit, Color, Audio, Export), Ash and Carbon themes, and Settings.
- Projects are saved continuously; after a crash or power cut, unsaved changes are recovered when the project opens.
- Errors explain what happened, why, and how to fix it. Logs and crash reports are kept for bug reports.
