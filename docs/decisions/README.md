# docs/decisions

Short records of decisions that change the plan, so the reason survives after the conversation is forgotten.

Name files `NNNN-short-title.md` (for example `0001-store-time-as-fractions.md`), each with:

- **Date**
- **Decision:** one or two sentences.
- **Why:** what made this the right call.
- **Instead of:** what was considered and dropped.
